⚙️ 站点管理

令牌获取：登录中转站控制台 → 个人设置 → 系统访问令牌 → 生成并复制。
站点地址不带斜杠结尾，如 https://docode.cc。
用户 ID：new-api 系（DoCode 等）用访问令牌查消耗时，必须额外填你的数字用户 ID（缺少会报 401 "New-Api-User header not provided"）。
  · 在哪里看：登录后点右上角头像 → 个人设置/账户，URL 里常带 ?i=1234 或页面底部显示「ID: 1234」。
  · 若填错会报 "does not match logged in user"，改成正确数字即可。
代理前缀：若直连被浏览器跨域拦截（看到「Failed to fetch」），把 NAS 上的 proxy.php 上传后填入此框即可，例如 https://你的域名/proxy.php?u=。

🌐 浏览器被跨域拦截了

这是 new-api 系中转站的常见问题：服务端 CORS 头不全，浏览器会拦掉响应。 服务端没问题，是浏览器层面的限制。
解决：在你能控制的服务器上跑一个 30 行的 PHP 反代（已帮你写好），浏览器走同源就不被拦了。

  1. 下载 proxy.php（和你现在看到的页面在同一个 GitHub 仓库 relay-usage 根目录）
  2. 上传到你的 NAS（飞牛 fnOS）上 php-comments-app 同目录
  3. 访问 https://你的域名/proxy.php?u=https://docode.cc/api/user/self 能返回 JSON 即成功
  4. 点「编辑站点」→ 填「代理前缀」= https://你的域名/proxy.php?u= → 保存 → 刷新
